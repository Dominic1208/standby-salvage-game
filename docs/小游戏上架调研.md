# 把《待机回收站》做成微信 / 抖音小游戏：规则和要做的事

调研日期：2026-10-31。规则经常变，正式提交前以两个平台后台的最新说明为准。
小游戏版只做**游戏本体**（回收站、员工、包裹、收藏品），不带“连接 AI”。

---

## 一、能不能上：结论

| | 微信小游戏 | 抖音小游戏 |
|---|---|---|
| 个人能不能上 | 能（免费游戏） | 能（免费游戏） |
| 赚钱方式 | 只能靠广告；个人主体开不了虚拟支付（内购） | 同左，个人主要靠广告 |
| 版号 | 不开内购就不需要；开内购必须有版号（个人基本拿不到） | 同左：版号是开通内购的凭证 |
| 软件著作权（软著） | 需要（或电子版权认证） | 需要；电子软著可用于上架资质，但做小游戏备案要正式软著；**一个软著只能对应一款在线游戏** |
| 游戏自审自查报告 | 需要 | 需要 |
| 备案（ICP 小程序备案） | 需要，先备案再上线 | 需要（有说法可以先上线后备案，以后台为准） |
| 名字 | 游戏名要和软著登记名一致 | 同左 |

**风险**：有文章提到，2025 年起部分地方开始把“纯广告变现、没版号”的小游戏也纳入监管，平台对没版号游戏的审核在收紧。个人主体的角色扮演类小游戏曾被要求转到企业主体。我们是经营/模拟类，暂时不在这一类，但要留意。

## 二、技术上：能不能直接把现在的游戏搬过去

**不能直接搬，建议换引擎重做。**

- 微信小游戏的包体限制：**首包不超过 4MB，所有包加起来不超过 30MB**。
- 我们现在用 Godot 导出网页版：引擎主程序压缩后约 10MB，游戏资源压缩后约 6MB。有人用 Godot 适配过微信小游戏（开源项目 godot-minigame），但体积已经逼近上限，还要绕开不少坑（比如微信读不了 .pck 文件，要改名成 .zip）。以后加内容很容易超限。
- 微信和抖音小游戏最常用的引擎是 **Cocos Creator**：可以一键打包成微信小游戏和抖音小游戏，体积小，文档和教程最多。

**建议**：用 Cocos Creator 重做一个“小游戏版”。玩法规则、数值、台词、图片全部沿用现在的（都在 `src/data/*.json` 和 `src/assets/art/`），只重写界面和逻辑代码。

## 三、小游戏版和电脑版的区别

| 部分 | 电脑版（现在） | 小游戏版 |
|---|---|---|
| 员工 | 你的 AI 对话 | 游戏里的 NPC 员工：派他们出门探险，过一段时间（比如 10–60 分钟）回来，带汇报和包裹 |
| 汇报内容 | AI 真实说的话 | 预先写好的冒险小故事（可以写很多条，随机组合） |
| 批准 | 真的批准 AI 的操作 | 去掉；可以换成“员工遇到麻烦，要不要花钱帮他”这样的小选择 |
| 存档 | 电脑上 | 小游戏自带的本地存储，可选微信云存档 |
| 赚钱 | 无 | 激励视频广告：比如破产时“看个广告拿应急款”、包裹“看广告翻倍” |

## 四、你需要做的事（按顺序）

1. **定游戏名**：小游戏名要和软著名一致。“待机回收站”可以，但不能带 AI 工具的名字（Claude、DeepSeek 等是别人的商标）。
2. **申请软著**（中国版权保护中心，个人可以申请）：
   - 要准备：身份证、源代码前后各 30 页、软件说明书（带截图）。代码和说明书我可以帮你整理。
   - 时间：正式软著大约一到两个月（第三方说法，以实际为准）；电子版权认证更快，可以先用来上抖音。
3. **注册账号**：微信公众平台注册“小游戏”（个人主体，实名）；抖音开放平台注册开发者、创建小游戏。
4. **做小程序备案**（在微信后台填）。
5. **写游戏自审自查报告**（平台有模板，我可以帮你填）。
6. **提交审核**，通过后上线；想赚广告费再开通流量主（广告）。

我负责的部分：用 Cocos Creator 重做小游戏版、准备软著用的代码和说明书、自审报告草稿、上架截图和介绍文字。

## 五、电脑版以后怎么更新

现在：每次更新都要重新下载整个压缩包（66MB）。

可以改成**自动检查更新**：
- 连接程序启动时去 GitHub 看有没有新版本；有的话，电脑上的设置页提示“有新版本”。
- **只改了游戏内容**（玩法、数值、收藏品、图片）：一键下载新的游戏文件（十几 MB），不用重装，手机刷新就是新版。
- **改了连接程序本身**：还是要下载新的压缩包，但设置页会给出下载链接和更新说明。

这个改动需要先把 GitHub 仓库公开（或者另建一个公开的“发布”仓库），因为别人的电脑要能访问到更新文件。
