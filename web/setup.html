待机回收站

AI 在干活，你在手机上经营回收站。AI 要你批准时，员工会推门进来请示。

✓程序在运行

1用手机扫码

手机和这台电脑连同一个 Wi-Fi，用相机扫左边的二维码，会自动配对。
以后直接打开这个网址就能回来玩，存档会同时保存在手机和电脑上。

iPhone：用 Safari 打开后点「分享 → 添加到主屏幕」，以后像 App 一样从桌面打开。

手机打不开？多半是第一次运行时 Windows 防火墙没点「允许」：到「设置 → 隐私和安全性 → Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里勾上「待机回收站」。

2连接你的 AI（只需要一次）

点一下就连上（用 DeepSeek、Kimi 等国内模型的 Claude Code，点 Claude Code 那个就行）。改动前会自动备份设置文件，随时可以断开。

连接后，新开的 Claude 会话才会生效。改动前会自动备份你的设置文件，随时可以断开。 接了 DeepSeek 接口的会自动算作 DeepSeek 员工（蓝色）。

3试一下

点下面的按钮，手机上会出现一条模拟请求（不会影响电脑）。真实测试：让你的 AI 新建一个文件，看手机上有没有员工推门。

4开机自动运行（可选）

打开后，电脑开机就会在后台启动待机回收站，不用每次双击；手机直接从主屏幕图标进去玩。

关掉那个黑色窗口，待机回收站就会停止。连接程序没开时，AI 照常在电脑上问你，永远不会自动批准。
