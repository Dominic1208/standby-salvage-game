# 《待机回收站》上架微信、抖音小游戏：一步一步来

> 写于 2026-11-01。平台规则经常变，每一步以后台页面上的说明为准。
> 这份教程假设你用**个人身份**上架**免费**小游戏（不开内购，以后可以加广告）。

## 先看全局：要做哪些事、要等多久

```
今天就能做                       要等几周
───────────────────────          ─────────────────────────
① 申请软著（网上填表）  ───等 30 个工作日左右───→ 拿到软著证书
② 注册微信小游戏账号                              │
③ 注册抖音开发者账号                              ▼
④ 在开发者工具里导入游戏、真机试玩       ⑤ 填资质、备案（备案要等 1～3 周）
                                         ⑥ 上传代码、提交审核（1～7 天）
                                         ⑦ 发布上线
```

**最慢的是软著，所以今天先申请软著。**软著证书上的名字必须和小游戏名字一致，两个平台都要。

## 第 ① 步：申请软件著作权（软著）

**在哪**：中国版权保护中心 https://www.ccopyright.com.cn → 著作权登记 → 软件登记（个人可以自己办，不用找代理）。

**费用**：官方登记费 2024 年 4 月起免收（以官网为准）。网上那些几百块的“加急代办”是代理费，可以不花。

**时间**：受理后大约 30 个工作日出证书。

**怎么填**（网上填表时对照）：

| 栏目 | 填什么 |
|---|---|
| 软件全称 | **待机回收站游戏软件** |
| 软件简称 | **待机回收站** |
| 版本号 | **V1.0** |
| 著作权人 | 你本人（个人），上传身份证 |
| 权利取得方式 | 原始取得 |
| 权利范围 | 全部权利 |
| 开发完成日期 | 2026-11-01 |
| 首次发表日期 | 2026-11-01（GitHub 已公开）。也可以选“未发表” |
| 开发方式 | 独立开发 |
| 硬件环境 | 智能手机（安卓、苹果） |
| 软件环境 | 微信、抖音小游戏运行环境 |
| 编程语言 | JavaScript |
| 源程序量 | 约 1850 行 |
| 主要功能和技术特点 | 抄 `上架文案.md` 里“详细介绍”的前半段，再加一句“基于 Canvas 2D 绘制，数据驱动，单机运行，存档保存在本地” |
| 程序鉴别材料 | 上传 `软著-源程序.pdf`（不到 60 页，全部提交） |
| 文档鉴别材料 | 上传 `软著-用户手册.pdf` |

**注意**
- **一份软著只能对应一款在线游戏**。微信和抖音上的是同一款游戏，可以共用。
- 软著名字以后改起来很麻烦（名字改了要重新备案），现在就定好“待机回收站”。
- 网上提交后，按页面提示打印申请表、签字、上传扫描件（有些流程还要邮寄纸质材料，按官网最新要求来）。

## 第 ② 步：注册微信小游戏

1. 打开 https://mp.weixin.qq.com → 右上角“立即注册” → 选 **小程序**（小游戏也在这里注册）。
2. 用一个**没注册过公众号、小程序的邮箱**注册，激活。
3. 主体类型选 **个人**，填身份证、姓名，用你的微信扫码实名验证。
4. 登录后台 → 左侧“设置” → “基本设置” → **服务类目** → 添加“游戏 → 休闲游戏”（或后台能选的经营、模拟类）。选游戏类目后，它就是“小游戏”了。
   - 这时会让你上传**软著**和**自审自查报告**。软著还没下来的话，可以先空着，后面再补。
5. 名称填 **待机回收站**，图标上传 `图标-144.png`，简介从 `上架文案.md` 复制。
6. 后台“开发管理 → 开发设置”里复制 **AppID**，填进 `minigame/appid.json` 的 `"wechat"`，然后重新打包：
   ```bash
   cd minigame && node build.mjs
   ```

## 第 ③ 步：注册抖音开发者，创建小游戏

1. 打开 https://developer.open-douyin.com → 登录（用抖音扫码）→ 注册开发者，选 **个人**，上传身份证正反面（要清楚，有效期要填对）。审核 1～2 个工作日。
2. 控制台 → 创建应用 → **小游戏** → 名称 **待机回收站**。名字一年只能改 2 次，所以一次填对。
3. 复制 **AppID**，填进 `minigame/appid.json` 的 `"douyin"`，重新打包（同上）。

## 第 ④ 步：用开发者工具试玩、真机预览

### 微信
1. 下载“微信开发者工具”（稳定版）：https://developers.weixin.qq.com/minigame/dev/devtools/download.html
2. 打开 → 小游戏 → **导入** → 目录选 `D:\AI\小游戏\minigame\dist\wechat` → AppID 选你的（还没有就点“测试号”或“游客模式”）。
3. 左边模拟器能直接玩。点上方“预览”，用手机微信扫码，在真机上玩一遍。
4. 右上角“详情 → 本地设置”里，勾上“将 JS 编译成 ES5”，可以兼容老手机。

### 抖音
1. 下载“抖音开发者工具”：在 https://developer.open-douyin.com 的小游戏文档里搜“开发者工具”，进下载页下载 Windows 版
2. 新建项目 → 导入 → 目录选 `D:\AI\小游戏\minigame\dist\douyin` → 填 AppID。
3. 点“预览”，用抖音扫码在真机上试玩。

**真机上要看的几件事**（我在电脑上的模拟器里都过了一遍，但真机才算数）：
- 右上角的“…”和“○”胶囊按钮，有没有挡住游戏里的按钮
- 有没有声音（第一次点“开始”后才有音乐，这是平台规定的）
- 派员工出门 1 分钟，关掉小游戏再打开，员工有没有按时回来
- 揭穿骗子、出价、打烊、拆包裹、抽造型都点一遍

有问题就把截图或录屏发给我。

---

## 第 ⑤ 步：资质和备案（软著下来以后）

### 微信
1. 后台“设置 → 基本设置 → 服务类目”，补传**软著证书**和**自审自查报告**（自审报告用 `自审自查报告-草稿.md` 的内容填进官方模板，手写签名）。
2. 后台首页会提示 **小程序备案**，点进去：
   - 填主体信息（你的身份证）、小程序信息（名称、类目、简介要和前面一致）
   - 手机上做**人脸核验**
   - 平台初审 1～2 天，然后工信部短信核验（**收到短信 24 小时内要回复**），管局审核 1～3 周
3. 后台“设置 → 服务内容声明 → 用户隐私保护指引”：按 `上架文案.md` 填“不收集任何信息”。

### 抖音
1. 控制台 → 你的小游戏 → **基础信息 → 资质信息**：
   - 上传**软著证书**（照片要清楚，不能有水印。软著上的著作权人必须是你本人，名称要和小游戏名一致）
   - **游戏自审自查报告**：在线读一遍，勾选确认
2. **小游戏备案**：控制台里按提示填，详细介绍（120～300 字）从 `上架文案.md` 复制，截图按 `截图/` 里的顺序上传（第一张必须是有游戏名称的启动页）。
   - 注意：抖音的备案要**正式的软著证书**，电子软著只能用于资质准入，不能用于备案。
3. **ICP 备案**：按后台提示做，流程和微信差不多（人脸核验 + 工信部短信 + 管局审核）。

---

## 第 ⑥ 步：上传代码、提交审核

### 微信
1. 开发者工具右上角 **上传** → 版本号填 `1.0.0`，备注填“首个版本”。
2. 后台 → 管理 → **版本管理** → 开发版本 → **提交审核**。
3. 审核 1～7 天。被打回就把原因截图发我，我来改。

### 抖音
1. 开发者工具 → **上传** → 版本号 `1.0.0`。
2. 控制台 → 版本管理 → **提交审核**。

## 第 ⑦ 步：发布

审核通过后，在后台“版本管理”点 **发布**，大家就能搜到了。

---

## 以后：赚广告费（可选）

1. **微信流量主**：小游戏累计用户达到 **1000** 后，在后台“推广 → 流量主”申请开通。开通后创建一个“激励视频广告”，把广告位 ID 填进 `minigame/data/ads.json` 的 `"wechat"`，重新打包上传。
2. **抖音**：后台“变现 → 广告”开通后，同样把广告位 ID 填进 `ads.json` 的 `"douyin"`。
3. 游戏里已经留好了两处“看广告”：
   - 店被收走时，看广告让收债人再宽限一天
   - 每天看一次广告免费抽一次造型

   没填广告位 ID 时，这两个按钮不会出现。

**广告规范**：只能是玩家自己点的激励视频；不能弹窗强制看，不能挡住按钮，广告不能占页面一半以上。

## 常见被打回的原因（我已经提前处理了的）

| 原因 | 处理 |
|---|---|
| 游戏内有英文 | 台词里的英文全部换成中文了 |
| 封建迷信（算命、开光、塔罗……） | 小游戏版删掉了相关的顾客、货物、收藏品 |
| 按钮和右上角胶囊重叠 | 游戏顶部从胶囊下面开始；“返回”都放在左上角 |
| 自动播放音乐 | 点“开始”后才放 |
| 健康游戏忠告文字不对 | 启动页一字不差地照抄了官方文案 |
| 自己画的适龄标识不规范 | 游戏里不画，只在后台选 8+ |
| 抽卡涉嫌赌博 | 只用游戏币，不能充值，概率公示 |
| 名字和软著不一致 | 软著全称“待机回收站游戏软件”，小游戏名“待机回收站” |
| 收集隐私 | 什么都不收集，不需要登录 |

## 更新游戏

改完代码后：
```bash
cd minigame && node build.mjs
```
然后在开发者工具里重新上传，提交审核。小游戏会自动更新到新版本，玩家不用重新下载。存档在玩家手机里，更新后还在。
