# 《待机回收站》开发记录（视频素材）

> 用途：之后做一期视频——这个构思怎么来的、做了哪些、怎么玩。截图在 `devlog/screens/`。
> 每次有进展就往下追加，保留"走过的弯路"，视频里最有意思的往往是这些。

## 0. 构思从哪来（2026-10-31）

- 痛点：让电脑上的 AI（Claude Code、Codex）干活时，它经常弹出"要不要批准这一步"，人不在电脑前就卡二三十分钟
- 想法：做一个手机小游戏，等 AI 的时候玩；AI 要批准时，游戏里的"员工"推门进来请示，点一下就处理掉
- 定位讨论：核心价值是"不漏掉 AI 的确认请求"，游戏是让人愿意一直开着它的理由
- 安全底线：真实批准不能包装成开宝箱按钮——员工进门只是入口，批准卡片是全屏纯文字，批准要滑动

## 1. 用 AI 拷问自己（2026-10-31）

- 下载开源框架 Claude-Code-Game-Studios，按它的流程 `/start → /brainstorm`（minimal 模式）
- 用"拷问我"的方式一轮一轮问清楚：平台（网页版）、先接哪个 AI（Claude Code，因为钩子能拦截平时开的会话）、玩法
- 参考 Steam 上的《深空当铺：可能是偷的》，只借"鉴定、砍价、还贷"的循环，主题改成"什么都收的回收站"
- 名字从"深空当铺 × AI 员工"改成《待机回收站》：AI 在干活，你在待机时间里经营回收站
- 产出：一页游戏简报 `design/game-brief.md`

## 2. 第一版：先跑通最难的链路

- 电脑端连接程序（Python）+ Claude Code 钩子 + 手机网页外壳 + Godot 4 游戏
- 截图 01：第一版界面，全是色块占位
- 截图 02、03：模拟一条 AI 请求 → 员工推门 → 游戏自动暂停 → 全屏批准卡片 → 滑动批准 → 回到原处
- 坑：中文字体——Godot 网页版不能用系统字体，裁剪了 Noto Sans SC 到 1 MB

## 3. "能不能做个好看点的 UI？"

- 截图 04：重做界面——货架场景、对话气泡、像当票的货物卡、红色要价印章、收银机液晶出价屏

## 4. 研究《深空当铺》的 Steam 评测，再改玩法

- 玩家最爱：顾客台词有梗、"（你获得了下层区声望）"这种小反馈、再来一回合的上瘾感
- 玩家最骂：重复、点太多、后期没目标、故事弱
- 改进：四种顾客性格台词、街坊口碑、快捷出价 5/7/9 成、每日订单、7 天还贷（截图 05）

## 5. 让 Codex 画美术

- Claude 写美术需求，交给本机的 Codex 生成：8 位顾客、8 件货物、店铺背景（截图 06、art-*）
- 一个 AI 写代码、另一个 AI 画图——这本身就是这个产品想解决的场景

## 6. 第一次上 iPhone 就报错

- 截图 07：Godot 网页版要求 HTTPS，局域网 http 打不开
- 解决：单线程版本其实不需要，导出脚本跳过这项检查；音频接口在非 HTTPS 下也没有，改成由网页外壳播放声音

## 7. 用户试玩反馈：5–6 分，"有点好玩"（2026-10-31）

反馈：没有声音玩不下去；货物太少；质疑只能点一次不合理；想要员工带回包裹和收藏品。

- 质疑可以反复点：每次都消耗耐心，撒谎的人第二次起可能心虚招认，老实人会越来越生气
- 货物库：151 种基础货物 × 12 种成色名头（祖传的、山寨版、网红同款……）= 1812 种名字，混入网络热梗故事
- 顾客：20 种原型立绘（复用），每种配 3 个名字和一种性格
- 声音：本机 ACE-Step 生成背景音乐（店铺主题、打烊），Python 合成 15 个音效
- 员工包裹（截图 08）：处理一条 AI 请求（批准或拒绝都一样）→ 小纸包；确认 AI 完成汇报 → 大木箱；拆出钱、收藏品、情报、口碑，也可能是奶茶报销单
- 收藏图鉴（16 件有梗的收藏品，跨局保留）、存档恢复

## 8. "太复杂了"——一键启动 + 让用户的 AI 自己接自己（2026-10-31 晚）

- 用户反馈：连接步骤太麻烦。目标改成：GitHub 下载 → 解压 → 双击 → 手机扫码就能玩，AI 只连一次
- 打包成不用装 Python 的 `待机回收站.exe`（PyInstaller），双击后自动打开电脑设置页（截图 10）：二维码扫码自动配对、"复制这句话发给你的 AI"
- 用户的点子：连接方式写成一份 Skill，交给用户自己的 AI 去接——每个 AI 最懂自己的配置
- 通用钩子 `hook --agent <名字>`，支持 Claude Code / Codex / Gemini CLI / Qwen Code / Copilot CLI / Cursor 的输出格式，用模拟输入自测全部通过（还没有在真实 AI 会话里测过）
- 安全底线不变：待机回收站没开或手机没处理，绝不自动批准
- DeepSeek：中国用户最常见用法是 Claude Code + DeepSeek 接口，钩子按接口地址自动识别，员工算 DeepSeek（蓝色）
- 存档在电脑上也备份一份，换了网络地址也能找回

## 9. 员工和主页面（用户的点子）

- 每个"AI 工具 + 项目"是一位员工，名字默认是项目文件夹名，可以改名
- 同一家 AI 的员工共用代表色，但长相不同：Claude 冷峻风、Codex 动物、DeepSeek 温柔风（全部亚洲面孔）、偶尔混入太空人等特别员工
- **弯路**：第一版员工画成了系白围裙的店员（为了方便染色）。用户一句话点醒："他们是外出探索的人，为什么会有围裙？"→ 全部重画成冒险家（星际、极地、丛林、深海、沙漠……），染色改用脖子上的白领巾
- 主页面：员工一个个推门进来站好（截图 11）；开店 / 收藏室 / 设置（音乐、音效音量）
- 点员工可以改名、随机换形象（纯随机，不捏脸，参考星露谷开局的随机）

## 10. "能不能高级一点"——大本营和文字冒险对话框

- 用户：不要底下彩色大框、不要"干活中"标签；做一个真实的房间，员工走来走去喝咖啡；点员工才弹出立绘对话框，像文字冒险游戏
- Codex 画了探险队大本营（截图 13）：后墙的门、左边咖啡机、右边皮沙发、中间地毯、下面是吧台，点吧台开店
- 员工头顶只留小白名牌（项目名 + AI 颜色小圆点），空闲的才标"空闲"；等你拍板的会走到吧台前、头上冒红色感叹号
- 点员工：大立绘 + 名牌 + 按 AI 性格写的台词（Claude 冷淡、Codex 皮、DeepSeek 温柔）（截图 14）
- 员工来请示时，网页外壳也用同样的立绘对话框（截图 15）
- 意外发现：这次开发用的 Claude 会话自己的钩子触发了，员工名单里出现了"art""tools"——说明 Claude 桌面应用里的钩子是会触发的
- 没做像素风：已有 30 张手绘立绘正好当对话框立绘，房间里用同一套图缩小 + 走路起伏，风格统一、省掉 30 套像素动画

## 11. 模拟一个新用户从 GitHub 下载

- 在干净的临时文件夹解压、用全新数据目录运行，按新用户视角走一遍，找出卡人的地方：
  Windows 未签名提醒、防火墙提示、连 AI 要来回好几步、每次都得记得双击 exe
- 简化：设置页加"进度清单"、**一键连接 Claude Code**（自动备份设置、只增删自己的条目、随时断开；DeepSeek 接口的 Claude Code 同样适用）、**开机自动运行**（截图 16）
- 用假的设置文件和假的启动文件夹测试，没有碰真实配置；全新解压的打包版从运行、一键连接到一次模拟批准全部走通

## 12. 第一次真机连接（2026-10-31 傍晚）

- 用户双击 exe、手机扫码、一键连接 Claude Code；新开的"哲学讨论"没有员工进来——原来那是**云端会话**，跑在 Anthropic 服务器上，碰不到本机的钩子
- 反而进来一位叫"小游戏"的员工：是开发这个游戏的 Claude 会话自己——证明本地会话的钩子真的通了
- 用户：员工应该叫对话名，不是文件夹名 → 钩子从对话记录里读 Claude 的对话标题，每个对话一位员工

## 13. 汇报、跳过、空空的店（用户的点子）

- 员工完成任务时，把 AI 最后那段汇报原文放进对话框，一页页翻；右上角"跳过"：有要批准的直接跳到请示，没有就"再见老板，我继续去忙了"（截图 17）
- 请示批准时也能先看到 AI 动手前说了什么
- 店里平时空着：只有等你拍板、或带着汇报回来的员工才推门进来，处理完就从门口走出去；设置里可以关掉完整汇报
- 员工回来一定带包裹，大部分是钱，也有收藏品和怪东西，当场拆（截图 18："帮人修了个 bug，人家硬塞的"）
- 所有形象所有 AI 通用、不重复分配，只用颜色区分：Claude 橙、DeepSeek 蓝、Grok 黑、ChatGPT/Codex 白
- 破产：钱花光且仓库空时，可借一次应急款（加到下次还款），再破产就从头来，收藏品保留
- 准备开源：远程改名为 template（避免误推到模板作者仓库）；模板是 MIT 许可，需要保留原作者版权声明

## 真实 AI 跑通测试（2026-10-31）

- 写了一个"假手机"测试程序：让真实的 AI 新建一个文件，程序自动在"手机"上批准，检查三件事：请求到没到、批准后 AI 有没有真的干活、干完员工有没有带汇报回来
- Claude Code + DeepSeek：三项全过 ✅（员工是蓝色的 DeepSeek）
- Codex：钩子一直"Failed"。原因：Codex 在 Windows 上用 cmd/PowerShell 跑钩子，带引号的程序路径两边都不认 → 改成不带引号（有空格时用短路径）。改了命令 Codex 要求重新信任一次
- Gemini：Google 停掉了个人免费账号用 Gemini CLI（让转去 Antigravity），只能用 API 密钥测

- Codex 修好后：完成汇报能到手机；但 Codex 弹出"要不要运行这条命令"时并不调用批准钩子，所以 Codex 目前只能在电脑上批准
- 中途程序对所有批准请求都报内部错误，重启就好了，原因没抓到 → 加了错误日志（数据目录 error.log），下次能直接看到

## 用户反馈：打开游戏时，正在跑的任务要直接算进来（2026-10-31）

- 以前要等 AI 下一次汇报才会出现员工；现在打开游戏就去读电脑上 Claude Code / Codex 的对话记录，最近 15 分钟有动静的都算"正在工作"的员工
- 一连上就弹提示："已连接电脑 · N 名员工正在工作"，点一下看名单（截图：screens/连上电脑提示几名员工在工作.jpg、screens/通讯台员工名单.jpg）
- 断开太久要重新配对：通讯台加了"重新配对"按钮；配对码输满 6 位自动连接，不用再点按钮

## 用户录屏反馈：员工叠在一起闪、积压汇报、看不到跳过（2026-10-31）

- 问题 1：带着汇报回来的员工在吧台前随机找位置 → 叠成一团；名单每次刷新又重新挑位置 → 一直闪
  → 改成固定站位排队（前排 3 个、后排 2 个），多出来的在门外，显示“门外还有 N 人排队”；只有最前面中间那位显示全名
- 顺手发现老 bug：每次第一个走进来的员工永远是透明的（进场等待时间正好是 0，淡入动画没触发）
- 问题 2：断线很久回来，一群人排队汇报 → 3 份以上时先问“一个个听”还是“全部收下”；全部收下 = 包裹全收、汇报以后在通讯台“最近”里点开看
- 问题 3：“跳过”只在汇报分好几页时才出现，而且挂在框角 → 现在对话框底下一排按钮：展开全文 / 跳过 / 继续
- 问题 4：汇报只带了 AI 最后一句话 → 现在带上这一轮 AI 说过的所有话；“展开全文”一次看完
- 问题 5：点“汇报”的员工却只是闲聊 → 汇报内容只存在内存里，程序重启就丢了；现在跟员工一起存到硬盘，点员工直接听汇报
- 截图：screens/吧台前排队.jpg、积压汇报-一个个听或全部收下.jpg、汇报对话框-展开全文-跳过.jpg、汇报全文.jpg、全部收下-包裹排队拆.jpg

## 用户试玩反馈：总在亏、右边空一块、钱给太多、没音乐（2026-10-31）

- “揭穿了骗子还是亏”：骗子的货真实价值只有参考价的 15%–70%，揭穿后原来只降 20% 要价 → 改成揭穿后按真实价值要价，还会告诉你“它其实只值 ¥X 左右”
- 写了经济模拟 tools/sim_economy.py，跑 2 万笔交易比较打法：改之前“不看线索 5 成→7 成”平均每位顾客亏 ¥23；改后（要价 1.0–1.25 倍、骗子 25%）小赚 ¥6，认真玩赚 ¥40，乱出价照样亏
- 加了 3 成出价按钮
- 商店页右边被切：顶栏一排最小宽度超过手机宽度 → 标题放不下时省略
- 员工带回的钱太多（一次两三百）→ 改成 10–20 块“按规矩上交一半”
- 收藏品扩到 1016 件（41 个系列），图鉴先看系列再看单件；目前同系列共用一张画
- 切应用回来没音乐：iOS 的声音状态是“被打断”而不是“暂停”，原来只处理暂停；点游戏画面的点击也传不到外层；主页音乐还不循环 → 三处都修了
- 截图：screens/商店页修好宽度-加3成.jpg、图鉴按系列.jpg、员工按规矩上交.jpg
